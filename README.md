# 前回超え筋トレメモ（kintorememo）

筋トレの記録をつけて、「前回の自分」を超えるための小さな Web ツールです。

## 使い方

- **記録の追加**：日付・種目（自由入力）・重量(kg)・回数・セット数・メモを記録できます。
- **種目で絞り込み**：種目名のリンクを選ぶと、その種目だけの一覧になります。
- **「前回」パネル**：種目を選ぶと、最新の日より前の直近セッション（日付・重量・回数・セット数）を「前回」として上に表示します。今日の目標を決める目安にしてください。記録が1日分しかない種目では「前回の記録はまだありません」と出ます。
- **休憩タイマー**：60秒／90秒／180秒のカウントダウンタイマーが付いています。
- **エクスポート**：全記録をテキスト形式（1行1記録）で書き出せます。AI に分析させたいときや、他のメモへ移すときに使えます。
- 記録は1件ずつ削除できます（確認ダイアログ付き）。

データは SQLite に保存されます。DB のパスは環境変数 `KINTOREMEMO_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 「前回」は日付単位のセッションで判定します。同日に複数回記録した場合は同じ日の分がまとまります。
- グラフ表示や自動の増量提案はありません。前回表示とタイマーだけのシンプルな道具です。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
